# 0006. Vite's recommended setup, with default settings

Status: Accepted
Date: 2026-11-03

## Context

The project aims for each tool's recommended setup: every tool on its latest stable release, with default or preset settings and nothing overridden, unless an exception is needed.

- Vite's recommended setup is its official React TypeScript template, generated by `create-vite` 9.3.3: Vite 8, `@vitejs/plugin-react` 6, TypeScript 7.0, oxlint and React 19.
- TypeScript 7 is strict by default: a project without a `strict` setting still rejects implicit `any` and possibly undefined values.
- Better's web template lints with ESLint 7 and Airbnb's configs, and sets Prettier to single quotes. ESLint 7, 8 and 9 have all reached [end of life](https://eslint.org/version-support/), and Airbnb's base config supports only ESLint 7 and 8.
- Node.js 26 became the long-term support line on 2026-10-28, with [26.13.0](https://nodejs.org/en/blog/release/v26.13.0). Medplum's `@medplum/core` supports Node.js 22.18 and later 22 releases, or 24.2 and later (its [`engines`](https://github.com/medplum/medplum/blob/v5.2.13/packages/core/package.json)).

## Decision

- Start from `create-vite`'s React TypeScript template as generated, and keep its settings: `tsconfig.json`, `tsconfig.app.json`, `tsconfig.node.json`, `vite.config.ts`, `.oxlintrc.json` and `.gitignore`.
- Lint TypeScript with oxlint, as the template does.
- Format with Prettier at its default settings, with no configuration file.
- Lint Markdown with remark and `remark-preset-lint-recommended`, plus `remark-gfm` so that tables and task lists are read correctly.
- Run Husky and lint-staged on commit with checks only: Prettier, oxlint and remark report problems and never change files, so that a commit holds exactly what its author reviewed. A pre-push hook refuses pushes to `main`.
- Pin Node.js 26.13.0 in `.nvmrc`, so that `nvm use` and continuous integration pick the same version, with matching `@types/node`. No `engines` field: an exact pin there warns on every other patch release.
- Keep every dependency on its latest stable release.

Exceptions to the template and to the defaults:

| `lang="en"` in `index.html`                                         | `lang="en-US"`                                                                                                                                                    | US English throughout (`AGENTS.md`)                                                                                                                                                                                                                                                                                                             |
| The template's demo: logos, styles, counter and favicon             | Removed                                                                                                                                                           | The first pull request is an empty app                                                                                                                                                                                                                                                                                                          |
| The template's code style                                           | Formatted with Prettier's defaults: semicolons, double quotes                                                                                                     | Prettier at default settings                                                                                                                                                                                                                                                                                                                    |
| `include` in `tsconfig.node.json`                                   | Adds `vitest.config.ts` and `scripts`                                                                                                                             | The type check covers the Vitest configuration and the Node.js scripts, such as `npm run load:example` ([0008](0008-departures-from-the-template.md))                                                                                                                                                                                           |

## Consequences

- Upgrades stay simple, because the only settings that differ from each tool's defaults are the ones listed above.
- The conventions no default lint rule covers, such as no abbreviations, no comments and kebab-case file names, are checked in review.
- The setup differs from Better's template in its linter and quote style ([0004](0004-better-frontend-conventions.md)).

## Alternatives considered

- **ESLint 10 with the rules of Better's template carried over**, plus rules to enforce the conventions. Not chosen: it needs custom configuration, and the setup is to use defaults.
- **ESLint 7 and Airbnb's configs, exactly as in Better's template.** Not chosen: ESLint 7 reached end of life in 2022.
